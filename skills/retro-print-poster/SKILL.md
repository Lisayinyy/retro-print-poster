# 诗意复古海报

把用户的一张照片做成 3:4 竖版诗意复古印刷海报。生成工具是内置的 `image_synthesize`（MiniMax H3 Image），用户照片作为参考图传入 `input_file_paths`。

成片的固定版式（自上而下）：

- 上方约 1/3：暖白纸色留白，左右错落两段英文小诗（小号打字机字体）；右上角一张带细边框的原图缩略图，下方标注 `ORIGINAL`。
- 中部：一个横跨画面的巨大高对比衬线大写英文单词，颜色取自照片。
- 下方：风格化的原照片场景，主体从原场景向上延伸，穿过大字、遮住部分笔画、越过字顶进入留白。
- 全画面：青 / 洋红 / 黄圆形彩色半调网点，暗密亮疏，像复古杂志印刷。

## 1. 收照片

1. 用户附图或给出路径。`input_file_paths` 只接受**当前工作区内**的本地路径：照片在工作区外（如下载目录、`[Image #1]` 的临时目录）时，先复制到工作区 `posters/source/`，文件名用 ASCII，再引用复制后的相对路径。
2. 用户只把图贴在对话里、没有可读的本地文件时，请用户把图片文件拖进来或给出路径；不要用文字描述代替参考图。
3. 用户一次给多张照片：每张照片单独出一张海报，各自拟定单词和诗句；同一批的单词不要重复。
4. 照片里有可辨认的他人肖像时，只处理用户本人或已获本人同意的照片；不生成公众人物海报。

## 2. 看图拟定方案

自己看每张照片（你能直接看图，不要调用 `images_understand`），为每张定下五项。用户已指定的项照用户的来，其余自己定：

| 项 | 怎么定 |
|---|---|
| 主体 | 照片里最有辨识度、能自然向上延伸的那一个：一束花、一根枝条、举起的果实、人物的头部和上身、鸟的头颈、天鹅的长颈。写清它在画面里的位置和特征。俯拍或平铺的照片（水面上的花、桌上的果盘）主体不会"长"上去：改写成"主体最上方的花瓣/果实压在大字下半部前面、顶端越过字顶"。 |
| 大字 | 一个 4–6 个字母的英文单词，全大写，概括照片情绪或动作，例如 HUSH、DRIFT、MUSE、AWAKE、GATHER、SWAY、ZEST、SAVOR、BLOOM、RIPE、SHINE、PURE、FREE、GRACE、POISE。避免生僻词，最长不超过 7 个字母。 |
| 两段小诗 | 每段 2 行、每行 2–6 个英文单词，全小写，语法正确，两段互相接续。必须根据这张照片的具体内容（颜色、物体、光线、动作）现写，不要套用任何现成句子，下面只示范格式：`<第 1 行> / <第 2 行>.` |
| 大字颜色 | 从照片里最有代表性的颜色取：花瓣、果实、枝叶、墙面、羽毛、水色、衣物。给出颜色名，如 `deep vermilion red`、`mustard yellow`、`forest green`、`fig plum purple`、`cobalt blue`。与画面主色协调，在暖白和照片上都可读；不要默认用蓝色。小诗和 ORIGINAL 标注用同色系的深色。 |
| 光色情绪 | 依照原图强化一种：温暖午后阳光、清透晨光、金色逆光、柔和阴天等。深色、低调的照片（夜景、深色水面、暗背景）要整体提亮，照片上沿的暗部用渐疏的网点散进暖白，不能留一条水平分界线。 |

用户说"你看着办 / 直接做"或没有提出偏好时，不要提问，直接用自己拟定的方案生成，并在交付时把方案列出来。用户明确想自己选单词或颜色、但还没给出时，调用一次 `ask_user`（`async: false`），最多 2 题，每题最多 4 个选项（你拟定的候选），用 `recommended` 标首选，不要在 label 里写"推荐"。

## 3. 写提示词

每张海报一条 request。读取 `references/prompt.md`，把模板里的 `{SUBJECT}`、`{WORD}`、`{POEM_1}`、`{POEM_2}`、`{COLOR}`、`{MOOD}` 替换为第 2 步的方案，其余文字原样保留。

- 单词和诗句必须原样写进提示词并加英文双引号，模型照抄引号内的文字，拼写才可靠。
- 用户补充的要求（比如"大字放低一点""不要缩略图""诗句换成中文"）写在模板末尾的"补充要求"一行，并优先于模板默认值。用户要求中文诗句时，诗句改用中文并加中文引号，字体改为小号宋体。

## 4. 生成

一次 `image_synthesize` 调用提交全部张数（单次最多 10 条）：

```json
{
  "requests": [
    {
      "prompt": "<替换后的完整提示词>",
      "input_file_paths": ["posters/source/flower.jpg"],
      "output_file_path": "posters/20261110-1930/bloom.png",
      "aspect_ratio": "3:4",
      "resolution": "2K"
    }
  ]
}
```

- `output_file_path` 用 `posters/<YYYYMMDD-HHMM>/<单词小写>.png`，时间取当前本地时间。
- `aspect_ratio` 固定 `3:4`，`resolution` 固定 `2K`。
- 计费提示：活动期内（至 11 月 20 日）MiniMax Code 每个账号共有 10 次免费图片生成，每张图计 1 次，用完后按 H3 Image 正常计费。用户一次要出 4 张以上时，开工前用一句话告知张数和计次。
- 调用失败时如实说明原因（例如内容审核、额度用尽、参考图读取失败），不要换用其他生图工具或网上图片充数。

## 5. 逐张质检

生成后用 `read` 打开每张成片，对照原照片和方案检查：

- **文字**：大字拼写与方案完全一致，整词在画面内、首尾字母没有被画幅切掉，字母完整可读，被主体遮挡的笔画不超过约三分之一；两段小诗逐词核对拼写，没有多出的标题、乱码或水印；缩略图下方是准确的 `ORIGINAL`。
- **主体**：从下方原场景连续长上来、穿过大字并越过字顶；比例正常，没有被拉长的头颈、扭曲的肢体、漂浮或断开的物体，没有凭空多出的物体。
- **画面衔接**：上下是一张连续画面，照片上沿由网点渐疏散入暖白；没有矩形拼接、水平分界线、笔直或撕纸状横切边、抠图白边或生硬渐变；能看到彩色圆形网点，不是普通噪点或划痕；上方留白相对干净。
- **缩略图**：在右上角，完整展示原图、未裁切，没有压住诗句或主体。
- **输出形式**：只有一张海报，不是拼图、样机或带相框的展示图。

有问题的那张，告诉用户问题在哪，询问是否重做这一张（重做同样计 1 次）；重做时在"补充要求"里针对问题加约束（例如拼错就再强调单词逐字母拼写 `B-L-O-O-M`，字被切边就写明整词左右留边，主体没穿字就写明主体顶部必须高于大字顶边）。免费额度按次计，**不要未经用户同意自动重做**；用户说了"直接做 / 你看着办"也只代表方案不用问，不代表可以重做。

## 6. 交付

用一张表列出成片：文件路径、大字、两段小诗、大字颜色、质检结论。然后补充：

- 成片为 2K、3:4 竖版，适合直接发小红书、朋友圈或做手机壁纸。
- 想换单词、换颜色、换诗句，或换一张照片再做，直接说即可（继续计次）。
