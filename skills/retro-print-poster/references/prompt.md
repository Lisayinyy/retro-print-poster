# 海报提示词模板

用法见 SKILL.md 第 3 步：替换 `{SUBJECT}`、`{WORD}`、`{POEM_1}`、`{POEM_2}`、`{COLOR}`、`{MOOD}`、`{EXTRA}`，其余文字原样保留；没有补充要求时删掉最后一行"补充要求"。

- `{SUBJECT}`：中文描述主体及其位置，如"画面中下部那束白色木槿花"。
- `{WORD}`：全大写单词，如 `BLOOM`。
- `{POEM_1}` / `{POEM_2}`：两段小诗，每段两行之间用 ` / ` 分隔，如 `softness stays / where the light falls.`。
- `{COLOR}`：英文颜色名，可附中文，如 `deep vermilion red（朱红）`。
- `{MOOD}`：中文光色情绪，如"温暖的午后阳光"。

```text
请将我上传的照片制作成一张 3:4 竖版诗意复古印刷海报。保留原照片的关键场景、视角、姿态和主体关系，不随意增添物体。本次向上延伸的主体是：{SUBJECT}。

上方约三分之一为干净的暖白纸色留白，左右错落放置两段与照片情绪呼应的简短英文诗句，使用克制的小号打字机字体，逐字照抄以下文字，不增不减：第一段（偏左上）"{POEM_1}"；第二段（偏右，略低）"{POEM_2}"。

中部以横跨画面的巨大高对比衬线大写字呈现英文单词 "{WORD}"，字母必须逐个准确拼写为 {WORD}，整词完整位于画面内，左右各留出约 4% 的边距，首尾字母不得被画幅裁切。让真实摄影主体从下方原场景自然向上延伸，穿过大字、遮挡部分笔画，并明显越过字顶进入暖白留白。主体必须与原场景保持连接、比例正常；优先调整文字位置和取景，不要拉长头颈、扭曲身体或制造漂浮物。遮挡适量，保持单词清晰可读。

整张海报应是连续画面。利用主体轮廓、光线、背景色与网点疏密，让照片在字间及主体周围自然衔接留白，照片上沿用由密到疏的网点逐渐散入暖白纸面，避免上下矩形拼接、水平分界线、笔直或撕纸状横切边、抠图白边和生硬渐变。

大字颜色使用从照片中提取的 {COLOR}，与画面主色协调且保持可读对比。小诗和细节标记采用同色系深色。依据原图强化{MOOD}的光色情绪，同时保留照片辨识度。

在大字与风格化照片内部加入细密、清晰可见的圆形彩色印刷网点，青、洋红、黄等墨点可轻微错位，暗密亮疏。整体像复古杂志的彩色半调印刷，而非普通噪点或划痕；主体仍保持真实摄影材质，上方暖白相对干净。

右上角放一张宽约占画面 15%–18% 的原始照片缩略图，完整展示原图、保持比例、不裁切、不调色，配细边框，缩略图正下方用同色系深色小字准确标注 "ORIGINAL"，避开诗句与主体。

整体克制、诗意，英文准确，除上述两段诗句、单词 "{WORD}" 和 "ORIGINAL" 外不出现任何其他文字，无额外标题、水印、Logo 或无关装饰。只输出一张完整海报，不要拼图或样机。

补充要求：{EXTRA}
```
